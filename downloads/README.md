# Ops Fabric hosting package

[Download the portable ZIP](https://github.com/dhimanchaudhuri2016/OpsFabric/raw/refs/heads/main/downloads/OpsFabric-hosting-package.zip)

Extract it, open `OpsFabric/README.md`, configure your new URL, and publish the contents of `OpsFabric/dist/` to any static HTTPS host.

Includes the ready-built site, editable source, repeatable build, subfolder-compatible asset paths, new-host SEO setup, third-party licences and a checksum manifest. Four BT photos and two BT fonts remain externally hosted; their URLs are documented in the package. No API key or server/database is needed. Feedback opens an email draft.
